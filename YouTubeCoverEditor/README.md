# YouTube Cover Editor

Chrome-расширение для YouTube Studio: текст поверх автоматических кадров YouTube и установка результата обложкой в один клик.

## Установка
1. `chrome://extensions` → включить **Developer mode**.
2. **Load unpacked** → выбрать эту папку.

## Использование
1. Откройте загрузку видео или страницу видео (**Details**) в YouTube Studio.
2. Наведите курсор на кадр в блоке **Thumbnail** → кнопка «🏷 Текст на обложку» (или кнопка «🏷 Обложка с текстом» внизу слева).
3. Тайтл подставляется из поля **Title**. Настройте шрифт, размер, цвет, обводку, фон; текст перетаскивается мышью.
4. **Применить** (Ctrl+Enter) — обложка 1280×720 JPEG уходит в YouTube.

Если Studio не отдала поле загрузки, расширение попросит нажать **Upload file** — файл подставится без выбора.

Кадры подтягиваются в максимальном доступном разрешении (maxres → sd → hq), чёрные полосы обрезаются автоматически.
Требуется канал с доступом к custom thumbnails. Настройки стиля запоминаются.
